# Introduction to Old Testament Narratives: Lesson Games

A gamified study companion for the course *Introduction to the Old Testament Narratives* (Master of Divinity Programme, Global School of Open Learning, author Rev. John Silvanus). Each of the thirteen lessons has its own game, built from that lesson's own key terms, sections, takeaways and learning outcomes. Nothing here adds new reading or new hours.

## What is in this repo

```
.
├── README.md          This file
├── SCORING.md         XP, levels and badge rules
├── PROGRESS.md        Tick-box tracker for all thirteen lessons
└── lessons/
    ├── README.md      Index of lessons by unit
    └── lesson-01-… to lesson-13-…   One game file per lesson
```

## How a lesson game works

Every lesson file follows the same five levels, so once you have played one you can play them all.

| Level | Game | What it trains | Max XP |
| --- | --- | --- | --- |
| 1 | Term Cards: match clues to the lesson's key terms | 🧠 Head | 15 |
| 2 | Section Quests: pick any three quests, one for each major section | 🧠 ❤️ ✋ | 30 |
| 3 | Truth or Twist: spot the false statement | 🧠 Head | 10 |
| 4 | Boss: defeat the lesson's common misconception using its five takeaways | 🧠 Head | 20 |
| 5 | Heart and Hands: one reflection, one act of ministry | ❤️ ✋ | 25 |
| ★ | Signature Game: a creative game unique to the lesson | all | +5 bonus |

Answers sit inside collapsible `<details>` blocks so you can check yourself without seeing them early.

## Ways to play

- **Solo:** work down the file, tick the boxes, and keep your XP in the Scoreboard table.
- **Pairs:** use your study partner for Retell It Twice, Chiasm Builder, Voices Circle and the Highlight Sheet exchange.
- **Fellowship (3 to 5):** play the Signature Games together. They are designed for the study-group sessions already in the course guide, and work by phone call or WhatsApp.

## Using this on GitHub

1. **Fork** the repo (or click *Use this template* if it is marked as one) so you have your own copy.
2. Open a lesson file. GitHub renders the `- [ ]` boxes as checkboxes you can tick in the web editor, then commit.
3. Copy the Scoreboard table into [`PROGRESS.md`](PROGRESS.md) after each lesson.
4. Tutors can use Issues or Discussions for the forum activities, one thread per lesson.

## Guardrails

- **Heart quests are never graded for opinion.** They earn points for honest, complete engagement only.
- **Private reflection stays private.** Do not commit journals or prayers to a public repo. Use a private fork, or record evidence as a signed line from your study partner.
- **Hard texts are not played for points.** The herem games in Lesson 9 and the Exodus and Dalit theology dialogue in Lesson 8 reward listening, not winning. Any participant may pause the exercise.
